<h2>1. Clonar um repositório</h2>

git clone https://github.com/seuusuario/seurepositorio

<h2>2. Configurar nome e email</h2>
git config --global user.name "Seu Nome" <br>
git config --global user.email "seuemail@example.com"

<h2>3. Inicializar um repositório local</h2>
git init

<h2>4. Adicionar arquivos ao controle de versão</h2>
git add .

<h2>5. Registrar um commit</h2>
git commit -m "Mensagem do commit"
